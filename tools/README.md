# calculus · 高等数学（上册）期中自测与复习讲义

同济《高等数学》上册第 1–4 章的期中自测与复习材料：**四套真题卷 + 一套自编热身卷（共 80 题，每套 100 分 / 90 分钟）**，加配 **29 个考点的复习讲义**。

题库是一个 JSON 文件，页面由脚本从题库生成，**所有答案都用 sympy / mpmath 独立复算过**，讲义与题库由脚本对账，页面行为有 jsdom 端到端测试。

## 直接打开这两个文件

| 文件 | 用途 |
|---|---|
| `自测.html` | 点开就做题：90 分钟倒计时、交卷当场判分、错题自动展开解析、按章节给掌握度表 |
| `复习讲义.html` | 考点讲解（原理 + 名师方法 + 例题 + 易错点）、80 行逐题索引、辅助函数清单、考前易错清单 |

两个页面都是**自包含单文件**（无外部依赖，双击即可用）。

## 内容构成

- **四套卷结构**：选择 8×4 + 填空 6×4 + 计算 4×6 + 证明 2×10 = 100 分 / 限时 90 分钟。
- **题目出处**：第一、二、三套取自历年考研数学真题（以 2010–2024 为主，含 2003、2005 年各一道），**每题都标出年份 / 卷种（数一、数二、数三）/ 题号**；第四套为自编热身卷，已明确标注。
- **复习讲义**：29 个考点，统一按「一句话 → 为什么 → 怎么做 → 原理（推导）→ 名师方法（带出处）→ 本卷真题（关键一步）→ 例题 → 易错点 → 小练带答案」组织；每个考点都对应本卷的具体题号，做题与看讲解可以来回对照。
- **名师方法**：每个考点收录 2–4 条来自公开讲义、公开题解的通行讲法，逐条给出**可打开的出处链接**，并汇总为讲义附录 D（89 条）。只做转述与要点概括，不是课程原文。

## 文件说明

| 文件 | 作用 |
|---|---|
| `bank.json` | **题库（唯一真源，改题只改这里）** |
| `build.py` → `自测.html` | 题库 → 自测页（自包含单文件，无外链） |
| `check.py` | 题库自检：分值合计、题号、选项、`key` 必须被 `accept` 命中、得分点之和 |
| `verify_math.py` → `verify_out.txt` | 逐题数学复算（sympy 极限/求导、数值积分、根的个数扫描） |
| `verify_alias.py` | 每题 `accept` 里的每种写法与判分基准是否**数学等价** |
| `test_all.mjs` | 四套卷端到端测试（jsdom：空卷 0 分、全对满分、换写法判对、改判生效） |
| `复习讲义.md` / `notes_map.json` | 讲义正文 / 考点↔题号映射（唯一真源） |
| `methods/*.json` → `methods.json` | 名师方法数据（分章小文件 → 合并；唯一真源在 `methods/`） |
| `deepen/*.json` → `deepen.json` | 各考点的「原理」与「例题」 |
| `apply_deepen.py` | 合并上两类数据并注入 `复习讲义.md`（靠标记对幂等替换，可重复运行） |
| `build_notes.py` → `复习讲义.html` | 讲义 → 页面：注入逐题索引与名师方法索引、章/考点折叠、搜索 |
| `check_notes.py` | 讲义、考点地图、映射、题库、名师方法**五方对账** |
| `test_notes.mjs` | 讲义页面端到端测试（jsdom） |

## 怎么继续更新

```bash
# 改题：编辑 bank.json
python check.py && python build.py                 # 重新生成 自测.html

# 改讲义正文：编辑 复习讲义.md（考点↔题号的映射在 notes_map.json）
# 改名师方法 / 原理 / 例题：编辑 methods/*.json、deepen/*.json
python apply_deepen.py && python build_notes.py    # 注入数据并生成 复习讲义.html
python check_notes.py                              # 对账（退出码 0 才算过）

# 验证
python verify_math.py > verify_out.txt 2>&1        # 逐题复算，退出码 0 才算过
python verify_alias.py                             # 写法等价性
node test_all.mjs  自测.html    bank.json          # 页面端到端（需 jsdom）
node test_notes.mjs 复习讲义.html bank.json
```

> `python` 指装了 `sympy` / `mpmath` / `markdown` 的解释器；两个 `*.mjs` 需要 `node` 与 `jsdom`。
> 修改优先级：题库 → `bank.json`；讲义正文 → `复习讲义.md`；考点归类 → `notes_map.json`；方法与例题 → `methods/`、`deepen/`。**不要手改生成的 HTML 以及 `methods.json` / `deepen.json`**（合并产物），下次生成会覆盖。

## 出处与版权说明

- **真题**：历年考研数学真题（数一 / 数二 / 数三），来源为公开真题汇编与权威解析；每题在页面上标出年份、卷种与题号。版权归原出题方，本仓库仅用于个人学习整理，无商业用途。
- **名师方法**：按公开讲义、公开题解里的通行讲法转述，逐条给出出处 URL，内容属于方法概述而非课程原文。本科目以**张宇、武忠祥**的公开题解与讲义为主，另有 1 条来自**汤家凤**基础课笔记；其他老师（杨超、余丙森、李永乐等）在本科目上本次检索不到可核验的公开出处，因此**没有收录**——宁缺毋滥。
- **自编内容**：第四套热身卷、讲义中各考点的「小练」「例题」，以及全部生成/校验脚本为本仓库原创，已明确标注。
