第 1 章　函数与极限▾

本章在卷面上占 8 道选择 + 6 道填空里的一半以上，是性价比最高的一章。核心只有两句话：极限存在靠左右夹逼，无穷小比较靠化成同一个幂。

1.1 基本极限、等价替换与四则运算▾

一句话：把式子拆成「有限个已经知道的极限」，其中每个无穷小因子都换成与它等价的、最简单的那个。

为什么：等价无穷小替换之所以合法，是因为 lim(α/α′) = 1，于是 lim(αβ/γ) = lim(α/α′)·lim(α′β/γ) = lim(α′β/γ)。 换句话说它只允许你在乘除的位置动刀，因为那里是「同一个因子的缩放」。加减的位置上，两个无穷小相消，谁比谁大一个量级完全变了，替换就会出错（这正是不定式 0/0 的坑）。

怎么做：① 认出型（0/0、∞/∞、0·∞、∞−∞）；② 0/0 时先把极限存在的因子（趋向 1 或非零常数）单独拎出来；③ 剩下的乘积因子做等价替换；④ 出现加减相消，马上换泰勒（见 1.2）。

原理（为什么这招成立）：极限的四则运算法则只在各部分极限都存在时才成立，所以「拆项」必须先把极限存在且非零的部分算成数拿出去，剩下才是真正的未定式。等价替换在乘除位置合法的原因是无穷小乘除的阶可以合并：α=α′(1+o(1))、β=β′(1+o(1))，相乘后仍是 α′β′(1+o(1))；而加减位置 α−β=(α′−β′)+高阶项，只有 α′−β′ 与 α−β 同阶时才能替换，这正是 lim α/β≠1 的来源。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 武忠祥｜先定型，再选法：① 求极限的第一步不是算，而是判断型：0/0、∞/∞、0·∞、∞−∞、1^∞、0^0、∞^0 七种未定式里属于哪一种；② 型定了工具就定了：0·∞ 化为 0/0 或 ∞/∞；∞−∞ 通分或倒代换 u=1/x；1^∞、0^0、∞^0 一律化为 e^{v·ln u}；③ 0/0 型三步法：极限非零的因子先算出数；再用有理化、变量代换化简；最后按 等价无穷小 → 洛必达 → 泰勒 的优先级挑工具。（例：含参极限（求 a、b 那类）本质仍是求极限：先把参数当常数按型选法，再由极限存在反解参数。）
  • 武忠祥｜加减位置不能替换时，创造条件（+t−t）：① 加减位置能不能用等价替换，先看被换的两项是不是等价量：替换后比值极限为 1（或 −1）就不许换；② 口诀是「有条件要上，没有条件创造条件也要上」：人为 +t−t、+1−1，把和差结构配成能用等价替换的因式形式；③ 洛必达越做越繁时也走这条路：拆项加泰勒展开，而不是硬求导。（例：分子含 cos t − e^{−t²/2} 这类相减结构时，直接替换会互相抵消得 0（错），应拆项后用泰勒定阶。）
  • 通用技巧｜加减法可用等价无穷小的充要条件（比值判据）：① 乘除位置无条件可用：α~α′、β~β′ 则 αβ~α′β′、α/β~α′/β′；② 加减位置：α−β~α′−β′ 的充要条件是 lim(α/β)=c≠1；α+β~α′+β′ 的充要条件是 lim(α/β)=c≠−1；③ 常用差函数等价（x→0）：tan x−sin x~x³/2、x−sin x~x³/6、arcsin x−x~x³/6、tan x−x~x³/3、x−arctan x~x³/3。（例：反例：lim(tan x−sin x)/x³ 把两者都换成 x 得 0，实际是 1/2。正例：lim(e^{3x}−e^{5x})/(sin 2x−sin 7x)，因 3/5≠1、2/7≠1，可放心替换为 (3x−5x)/(2x−7x)=2/5。）

例题：求 lim_{x→0}(1−cos x)/(x sin x)：分子等价 x²/2、分母等价 x²（乘除位置可换），得 1/2。若在加减位置乱换（如把 tan x−sin x 两项都换成 x）会得 0，与真值 1/2 矛盾。

易错点：① 把 sin x ~ x 用在加减里，比如 (tan x − sin x)/x³，替换成 (x − x)/x³ = 0 就错了（正确是 1/2，见 1.2）；② 忘记 e^x − 1 ~ x 的 x 必须趋于 0——写成 e^{3x} − 1 ~ 3x 才对；③ 分式里 lim f(x)/3 存在不代表 f 存在，要整体看。

小练：求 lim (x → 0) (e^{x²} − 1)/(1 − cos x)。答案：2（分子 ~ x²，分母 ~ x²/2）。

1.2 泰勒展开定阶：什么时候不能用等价替换▾

一句话：分子分母出现加减相消时，把每一项展开到第一个不抵消的幂次，然后只留那一项。

为什么：等价替换只保留了主项，可两个主项相减正好抵消，剩下的信息全在被丢掉的高阶项里。泰勒展开就是「把丢掉的项按需要补回来」的正式说法。常用展开（x → 0）记这三个够用一张卷子：

  • sin x = x − x³/6 + o(x³)，tan x = x + x³/3 + o(x³)，arctan x = x − x³/3 + o(x³)
  • ln(1 + x) = x − x²/2 + x³/3 + o(x³)，e^x = 1 + x + x²/2 + x³/6 + o(x³)
  • cos x = 1 − x²/2 + x⁴/24 + o(x⁴)，(1 + u)^α = 1 + αu + α(α−1)u²/2 + o(u²)

怎么做：① 估一下要展到几阶——看分母的阶；② 每项展到「比分母高一阶」就停；③ 相加后把抵消的项划掉，剩下的最高阶项决定阶数和系数。

原理（为什么这招成立）：泰勒展开是把函数写成 x 的多项式加高阶余项，相减时同次项按系数合并：系数相等的项直接抵消，所以相减型必须展到系数首次不同的那一阶；分式型分母的次数决定精度，分子展得更高也无用，因为商里低于分母次的项都不影响极限。这就是「上下同阶、幂次最低」两条原则的由来。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 张宇｜泰勒定阶两条原则：A/B 型上下同阶、A−B 型幂次最低：① A/B 型（分式）：分子分母展开到相同的阶——分母是 x^k 就展到 x^k；② A−B 型（相减）：展到两项系数第一次不相等的那个最低次幂为止，这就是幂次最低；③ 停止判据：再展一阶后最低次幂系数不再恰好抵消就停，不必多展；相减结构若用等价替换会抵消，就必须改用泰勒。（例：lim(x+sin x)/x 中 x+sin x = x−(−sin x)，展到一次项得 x−(−x)=2x 即停。）
  • 武忠祥｜先看精度是否统一，再看要不要泰勒：① 凡出现和差结构（arcsin x−sin x、arctan x−tan x 一类），等价替换必然互相抵消，只能上泰勒；② 先试 ±1 配凑：能配成因式形式就用等价替换，配不成再展开；③ 精度统一：分子分母展到同次项再算，阶数不齐是这类题的头号失分点。（例：lim(arcsin x−sin x)/(arctan x−tan x) 需用 arcsin x=x+x³/6+o(x³) 一类展开，分子分母都展到 x³。）
  • 通用技巧｜幂次最低原则的完整算例：① 相减型求 (A−B)/x^n 时，A、B 各展到系数第一次不相等的那一阶再相减；② 只展到系数相同的那一阶会全部抵消，得到 0 的错误结果。（例：cos x−e^{−x²/2}：cos x=1−x²/2+x⁴/24+…，e^{−x²/2}=1−x²/2+x⁴/8+…，相减得 −x⁴/12+o(x⁴)，即 ~−x⁴/12（只展到 x² 会全抵消为 0）。）

1.3 无穷小的比较与阶▾

一句话：阶 = 化成 x^α 之后的 α；α 小的叫低阶（趋于 0 慢），α 大的叫高阶（趋于 0 快）。

为什么：比较两个无穷小，本质是看比值 α/β 的极限：等于 1 是等价，等于非零常数是同阶，等于 0 说明分子「更快地消失」是更高阶，等于 ∞ 则更低阶。所有判断都归结成「把两边都写成 x^α」。

怎么做：

  1. 把每个量化到 x^α 形式（用等价替换 + 变限积分「求导降一阶」）。
  2. 变限积分 ∫_0^{u(x)} f(t)dt 的阶 = f 在 0 处的阶 + u(x) 的阶（所以「求导一次降一阶」）。
  3. 排序题先各自算阶再比大小；含参数题让不抵消的最高阶相等即可。

原理（为什么这招成立）：无穷小的比较本质是比较趋向 0 的速度，用比值极限把速度差量化成阶数：f 分别是 g 的 k 阶无穷小时，f/g^k 极限是非零常数。等价无穷小是 k=1 且系数为 1 的特例，所以它可以用「比值的极限是否等于 1」来验算，而不必依赖背公式。有界量乘无穷小仍是无穷小，是因为乘不改变「趋于 0」这件事，只改变量级。

名师方法（公开讲义与题解的通行讲法，出处见下）

1.4 1^∞ 型与幂指函数极限▾

一句话：见到 [f(x)]^{g(x)} 一律先取对数，把它变成 g(x)·ln f(x) 的乘积型极限。

为什么：a^b = e^{b ln a}，而 e 是指数函数的复合，连续，所以可以把极限搬进指数：lim a^b = e^{lim b ln a}。取对数这一步把所有「幂」的麻烦都换成「乘」的麻烦。当 f → 1、g → ∞ 时，ln f ~ f − 1（f − 1 是无穷小），于是 lim g·ln f = lim g·(f − 1)——这就是教科书上的「1^∞ 型公式 lim f^g = e^{lim g(f−1)}」的来源，不用背，现场取对数就行。

怎么做：① 取对数；② 把 ln f 用 ln(1 + u) ~ u 化成 u = f − 1；③ 算 lim g·u（里面照常用等价替换/泰勒）；④ 答案写 e^{该极限}。

原理（为什么这招成立）：幂指函数既不能按幂函数求导也不能按指数函数处理，写成 e^{v ln u} 后它变成复合函数，底数问题转成指数上的乘积问题；1^∞ 型里 ln u=ln(1+u−1)~u−1，于是 u^v=e^{v ln u}=e^{v(u−1)}，只要算 v(u−1) 的极限即可，比算 v ln u 少一步等价替换。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 张宇｜幂指函数统一改写 u^v=e^{v·ln u}，1^∞ 另有简式：① 底和指数都含 x 的幂指函数，先写成 e^{v·ln u}，把幂指化为乘积再判型；② ∞^0、0^∞ 走 e^{v·ln u}（化成 0·∞）；1^∞ 可用简式 e^{v(u−1)}，只需求 lim v(u−1)；③ 看到根号先有理化；④ 考研最常出现的三个改写：x=e^{ln x}、u^v=e^{v·ln u}、x^x=e^{x·ln x}。（例：x→0+ 时 x·ln x = ln x/(1/x) 化为 ∞/∞，洛必达得 0，故 x^x=e^{x ln x}→1。）
  • 武忠祥｜幂指结构一律先写成 e^{…} 再求极限：① 遇到 (x/(1+x))^x 这类结构，先写 e^{x·ln(x/(1+x))}，把幂指极限变成指数上的极限；② 指数上允许用等价无穷小与洛必达；底数的替换仍要守乘除可换、加减谨慎的规矩；③ 求斜渐近线的截距时，同样用 e^{…}−1 的等价或泰勒处理无穷小。（例：k=lim_{x→+∞}(x/(1+x))^x=e^{lim x·ln(x/(1+x))}=e^{−1}，即曲线 y=x^{1+x}/(1+x)^x 的斜渐近线斜率为 e^{−1}。）

1.5 连续性与间断点的分类▾

一句话：间断点只可能在没定义的点、分段点、以及让式子分母为零/对数发散/指数爆炸的点；分类看左右极限是否都存在。

为什么：连续性只有一条判据——lim f(x) = f(x₀)（三件事：有定义、极限存在、二者相等）。间断点分类是这条判据的二分法：

  • 左右极限都存在 → 第一类：相等但 ≠ 函数值（或无定义）叫可去，不相等叫跳跃；
  • 至少一侧极限不存在或无穷 → 第二类：趋向 ∞ 叫无穷，来回震荡叫振荡（如 sin(1/x)）。

怎么做：① 先列出所有候选点；② 对每个候选点算左右极限（用等价替换定阶：分母趋于 0 且分子非零 → 无穷间断）；③ 按上面的二分法归类；④ 问「个数」的题目，每个候选点都要点名，别漏。

原理（为什么这招成立）：连续要求函数值、极限值、定义域三件事同时成立，所以间断点只能是这三件事之一出问题的地方——于是先找「候选点」比直接算极限更省事。分类的依据是左右极限这两个单侧极限的存在性与相等性，因为函数在一点附近的走向只有左侧和右侧两条路。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 张宇｜间断点先找候选点，再判四类：① 候选点只有两类：分段点（含 |x|、x²、√x² 这类隐含分段），以及无定义点（分母为 0、ln x 中 x≤0）；② 四类判法：可去（左右极限相等但 ≠f(x₀)）、跳跃（左右极限不等）、无穷（至少一侧为 ∞）、振荡（极限不存在且往复摆动）；③ 间断点只讨论点，不讨论区间。（例：sin x 在 x→∞ 时往复摆动，对应点为振荡型间断点。）
  • 通用技巧｜三个量排列组合：判定顺序固定：① 对候选点 x₀ 只看三个量：lim_{x→x₀+}f(x)、lim_{x→x₀−}f(x)、f(x₀)；② 顺序是：先看左右极限是否都存在 → 再比是否相等 → 最后与 f(x₀) 比；③ 左右极限都存在为第一类（相等但不等于 f(x₀) 或 x₀ 无定义为可去，不相等为跳跃）；至少一个不存在为第二类（为 ∞ 是无穷，振荡不存在是振荡）。（例：y=1/x 在 x=0 是无穷间断点；y=sin(1/x) 在 x=0 是振荡间断点。）
  • 通用技巧｜从连续三要素反推间断点：① 连续三要素：f 在 x₀ 有定义；lim_{x→x₀}f(x) 存在；极限值等于函数值；② 任一条不满足，x₀ 就是间断点——这是求间断点类题最快的切入点；③ 初等函数在其定义区间内连续，故间断点只可能出现在无定义点或分段点。（例：f(x) 在 x=1 无意义，则 x=1 必为间断点，无须再算极限。）

1.6 数列极限：递推、裂项与夹逼▾

一句话：数列求极限三条路——能递推的用单调有界准则，能求和先裂项，能放缩的用夹逼。

为什么：函数极限有洛必达、泰勒这些「重型工具」，但数列是离散的，导数用不上；能用的只有结构：单调 + 有界 ⇒ 收敛；夹在两个收敛到同一点的数列之间 ⇒ 收敛到同一点。所以做数列题第一步不是算，而是看结构。

怎么做：

  1. 递推式（x_{n+1} = f(x_n)）：先证有界与单调（用数学归纳法或 f 的性质），再令 lim x_n = A 代入递推式解方程（先证收敛才能代）。
  2. 求和式：先看能不能裂项（1/(n(n+1)) = 1/n − 1/(n+1)）或凑成定积分/等比求和，再取极限。
  3. 比较两个数列的「消失速度」：分别找出「至少多慢」和「至多多快」的界，比指数衰减速度。

原理（为什么这招成立）：夹逼定理把「算不出」的数列夹在两个能算出极限的数列之间，所以放缩的分母要「大同小异」——只有各项趋于同一个值时，左右两端才收敛到同一极限；分母大不同时两端极限不同，就必须换成定积分定义（把和式看成黎曼和）。单调有界准则来自实数的完备性：单调且有界的数列必收敛，因此证明的顺序是先有界后单调，最后才敢在递推式两端取极限。

1.7 变限积分函数：求导、极限与平均值▾

一句话：F(x) = ∫_a^{u(x)} f(t)dt 的一切都从 F′(x) = f(u(x))·u′(x) 出发；再配单调性、零点定理或「求导降一阶」定阶。

为什么：变限积分是用积分定义的函数，它天生连着两件工具：微积分基本定理（求导把它变回 f）与定积分中值/交换次序（把积分算成数）。考研题的套路固定：给了变限积分，就求导，然后看它落在哪一章的结论上（单调性 → 第 3 章；定阶 → 1.3；零点 → 3.5）。

怎么做：① 求导，注意上限是复合函数（还要乘 u′）；② 求平均值 = (1/(b − a))∫f，遇到「积分里还有积分」用交换积分次序（画区域）或直接分部；③ 定阶时用「求导一次降一阶」。

原理（为什么这招成立）：变限积分的导数之所以是「上限代入」，是牛顿-莱布尼茨公式与复合函数求导的组合：F(x)=∫_a^{h(x)}f 先看成 ∫_a^{u}f 与 u=h(x) 的复合，外层导数是 f(u)，再乘 u′=h′(x)；下限贡献一个负号，因为积分上下限互换要变号。被积函数含 x 时不能直接代入，是因为此时 x 不在「上限」而是在被积函数里，必须先把 x 分离出来。

  • 通用技巧｜变限积分与原函数：有第一类间断点就没有原函数：① f 连续时 ∫_a^x f(t)dt 就是 f 的一个原函数；② f 在区间上有第一类间断点或无穷间断点，则 f 在该区间上不存在原函数；③ 但变限积分 F(x)=∫_a^x f(t)dt 在 f 的可去、跳跃间断点处仍然连续（有限个点的函数值不影响积分面积）；跳跃间断点处 F 不可导，左右导数分别等于 f 的左右极限。（例：x=π 是 f 的跳跃间断点 ⇒ F(x)=∫_0^x f(t)dt 在该点连续但不可导，可直接秒杀选择填空题。）

第 2 章　导数与微分▾

这一章的题目有一个共同点：看上去是计算，其实是判断。「在 x = 0 处可不可导」「ξ 的位置趋于多少」这类问题，套公式会错，从定义出发一步就完。

2.1 导数定义：凑出差商▾

一句话：看到 f(x₀ + α) − f(x₀ + β) 这种「两点函数值相减」，就把它拆成两个标准差商，分母各自补成对应的增量。

为什么：导数是一个极限，不是一套公式。公式（乘积、复合）本身都是从定义证出来的，所以凡是题目里出现「抽象的 f」「f(0) = 0 但不给具体表达式」，都只能用定义。定义式 f′(x₀) = lim [f(x₀ + Δx) − f(x₀)]/Δx 的关键是减的那一项必须是 f(x₀)——题目给了 f(0) = 0，就是为了让你把 0 减掉。

怎么做：① 找到「已知函数值」的那个点（通常是 0）；② 把分子拆成若干个 f(某点) − f(已知点)；③ 每一项配一个与该增量相同的分母，凑成 f′；④ 用极限的线性性质相加。

原理（为什么这招成立）：导数是差商的极限，差商要求「同一自变量取两个值、函数值相减、除以自变量之差」，所以分子必须是一动一静，分母必须与那个「动」同阶。把 f(x₀+αh)−f(x₀+βh) 拆成两项，本质是用 f(x₀+αh)−f(x₀) 与 f(x₀)−f(x₀+βh) 两个合法差商分别凑出导数，再按系数相加。若极限点附近差商无意义（分母可取 0），导数定义本身不成立，此时不能谈导数。

  • 通用技巧｜导数定义等价形式的三条件：① f′(x₀)=lim_{Δx→0}[f(x₀+Δx)−f(x₀)]/Δx 存在，等价于 lim_{□→0}[f(x₀+□)−f(x₀)]/□ 存在；② 分子必须是一动一静；分母与 □ 同阶；□ 可左可右；③ 若 φ(x) 在 x₀ 的任意邻域内可取到 0，则 f(φ(x))−f(x₀) 作分子无意义，此时极限可能不存在。（例：lim_{x→0}[f(φ(x))−f(0)]/φ(x) 看着像导数定义，但 φ 若在 0 附近反复取零值，差商无意义，极限未必存在（选择题常在此设陷阱）。）

2.2 分段函数与绝对值型函数的可导性▾

一句话：分段点处只能用左右导数定义；含 |x − a|、√、ln 的式子先判断它在 a 附近「像 x − a 的一次项还是它的更高次项」。

为什么：常见结论 |x| 在 0 处不可导、x|x| 可导，来源都是同一个：|x| = ±x 分左右，左导 −1、右导 +1；而 x|x| = ±x² 左右导数都是 0。关键不在绝对值，而在「绝对值旁边乘了几次 x」：乘够一次就把它抹平了。所以这类题不要背结论，算左右导数。

怎么做：① 写出左右两侧的表达式（|x| = x（x > 0）或 −x（x < 0））；② 在分段点用定义算 f′₊、f′₋（含 lim_{x→0} x ln x = 0、lim x^k ln x = 0 这类结论）；③ 相等则可导，不等则不可导；④ 「变限积分在间断点是否可导」看被积函数的左右极限。

原理（为什么这招成立）：绝对值在尖点处左右导数反号，乘上系数 f 后能否抵消取决于 f 在该点的值：f(a)≠0 时左右导数仍反号，不可导；f(a)=0 时两边都含因子 f(a)=0，左右导数同为 0，可导。这就是「f(x)|x−a| 在 a 可导等价于 f(a)=0」的推导，也是分段点必须用定义判断而不是套公式的原因。

2.3 隐函数求导（含二阶）▾

一句话：方程两边同时对 x 求导，把 y 看成 x 的函数，y′ 就自然冒出来；求二阶导时，把一阶导的结果直接代入，不要再解一遍。

为什么：隐函数存在定理保证「局部能解出 y = y(x)」，但解不出来。既然解不出来，就不要解——对等式两边求导，得到的仍是一个关于 y′ 的一次方程，这就是隐函数求导的全部内容。之所以不用解 y，是因为求导是等式保持的运算。

怎么做：① 两边对 x 求导（含 y 的项按复合函数乘 y′；含变限积分的项同时用微积分基本定理）；② 把 (x, y) 的具体值代进去解 y′（先算出该点的 y，再用方程定值）；③ 求 y″：把 ① 的式子再求一次导，然后把已求出的 y′ 代进结果，最后代数。

原理（为什么这招成立）：隐函数求导的全部依据是把方程看成恒等式：满足方程的每个 x 对应唯一 y，于是 y 是 x 的函数，两边对 x 求导仍相等。含 y 的项按复合函数处理（链式法则），所以 e^y 的导数是 e^y·y′。先定值再求导，是为了把低阶导数值尽早代入，避免最后在含 y、y′ 的复杂式子里回代出错。

2.4 参数方程确定的函数求导▾

一句话：一阶导 dy/dx = (dy/dt)/(dx/dt)；二阶导先把 dy/dx 写成 t 的函数再对 t 求导，最后除以 dx/dt。

为什么：参数方程是「用第三个变量描述 x 和 y」，dy/dx 的含义没变，只是要用链式法则转换成对 t 的导数之比：dy/dx = (dy/dt)·(dt/dx) = (dy/dt)/(dx/dt)。二阶导最容易错在「直接对 dy/dx 再求一次 t 的导」——那时得到的是 d²y/(dt dx)，还差一个 dx/dt。

怎么做：① 分别求 dx/dt、dy/dt；② 相除得 dy/dx（尽量化简成 t 的简单表达式，能约就约——这是本节最省时间的一步）；③ d²y/dx² = d(dy/dx)/dt ÷ (dx/dt)；④ 代 t 的值（注意切点坐标也要用 t 算）。

原理（为什么这招成立）：参数方程里 x 与 y 都是 t 的函数，dy/dx 实际是两个微分之比，所以二阶导不能直接写 (d²y/dt²)/(d²x/dt²)——必须把 dy/dx 看成 t 的函数再对 x 求导，而「对 x 求导」= 对 t 求导再除以 dx/dt，这就得到分母上出现 (dx/dt)³ 的公式。

2.5 高阶导数：莱布尼茨公式与幂级数法▾

一句话：求 f^(n)(0) 用莱布尼茨公式（乘积型）或展开成幂级数后对齐系数（和式里含 x^k 时更快）。

为什么：莱布尼茨公式 (uv)^(n) = Σ C(n,k) u^(k) v^(n−k) 是乘积法则的 n 次重复。它的价值在于：多项式的导数从某阶开始全为 0，所以「多项式 × 好函数」的组合里只剩少数几项。若 f 本身是幂级数形式（如 x²ln(1 − x)），把 x^k 的 n 阶导公式 (x^k)^(n) = k(k−1)…(k−n+1)x^{k−n} 用上，只看 n 次以上的项即可。

怎么做：① 判断「谁是多项式、谁是能反复求导的函数」；② 用莱布尼茨，只保留多项式导数非零的那几项；③ 或把函数展开成 Σ a_k x^k，取 k = n 的系数乘 n!（即 f^(n)(0) = n!·a_n）。

原理（为什么这招成立）：莱布尼茨公式是二项式定理在求导上的对应物：每求一次导把一个因子的阶数挪给另一个，组合数来自「哪几次求导分给了 u」。多项式因子求导若干次后为 0，公式自然截断，所以含 xⁿ 因子的乘积只需有限项。求某点高阶导则用泰勒：幂级数里 xⁿ 的系数就是 f⁽ⁿ⁾(0)/n!，比反复求导快得多。

2.6 切线与法线▾

一句话：切线斜率 = 该点导数；法线斜率 = 负倒数（切线水平则法线竖直，反之亦然）。

为什么：两条直线垂直 ⟺ k₁k₂ = −1。导数给出的是切线斜率，剩下的是平面几何。参数方程、隐函数给的曲线也一样：先在点处求出 dy/dx。

怎么做：① 验证点在曲线上；② 求 dy/dx 并代点得 k；③ 切线 y − y₀ = k(x − x₀)，法线 y − y₀ = −(1/k)(x − x₀)。

原理（为什么这招成立）：切线是割线的极限位置：割线斜率 [f(x₀+Δx)−f(x₀)]/Δx 取极限即 f′(x₀)，所以切线斜率就是该点导数值。法线垂直于切线，斜率之积为 −1；切线水平时法线竖直，这是唯一需要单独处理的情形。两曲线相切要求位置与走向同时一致，因此必须同时满足函数值相等与导数值相等两个方程。

2.7 幂指函数求导▾

一句话：[u(x)]^{v(x)} = e^{v ln u}，先写成指数形式再求导。

为什么：幂函数求导要求指数是常数，指数函数求导要求底数是常数，两边都不是常数时哪个公式都不能直接用。统一办法是对数恒等式化成 e 的复合函数，那里链式法则畅通无阻。

怎么做：① 写成 e^{v ln u}；② 求导：(e^{v ln u})′ = u^v·(v′ ln u + v·u′/u)；③ 代数得值。

原理（为什么这招成立）：幂指函数 y=u^v 中底数与指数都随 x 变化，直接套 u^v 的形式求导没有现成公式，取对数或写成 e^{v ln u} 就是把「底数问题」转成「指数上的乘积问题」，从而可以用乘积法则与链式法则。两种写法等价，所以对数求导法与自己写 e 的指数求导结果必然一致。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 通用技巧｜对数求导法三步：① y=u(x)^{v(x)}（u>0）既不是幂函数也不是指数函数，不能套单一公式；② ① 两边取对数 ln y=v(x)ln u(x)；② 两边对 x 求导，左端为 y′/y，右端用乘积法则；③ 解出 y′ 并把 y=u^v 乘回去。（例：y=x^x：ln y=x ln x ⇒ y′/y=ln x+1 ⇒ y′=x^x(ln x+1)。）
  • 通用技巧｜化为指数函数：u^v=e^{v ln u}：① 恒等变形 y=e^{v(x)ln u(x)}，变成复合函数再求导，结果与对数求导法一致；② 防错原则：一切幂指函数先化成指数或取对数，否则会错用幂函数或指数函数的公式；③ 同一变形也用于幂指型极限：0⁰、∞⁰、1^∞ 型一律把幂指搬进指数。（例：y=(1+x)^{sin x} ⇒ y=e^{sin x·ln(1+x)}，y′=(1+x)^{sin x}[cos x·ln(1+x) + sin x/(1+x)]。）
  • 武忠祥｜幂指形式先写成 e^{…}，再连斜渐近线一起处理：① 求 (x/(1+x))^x 这类幂指形式的极限，先写 e^{x·ln(x/(1+x))}；② 斜渐近线的 b 用 e^{…}−1 的等价或泰勒处理无穷小；③ 适用条件是底数 u>0（保证对数有意义），底数可能为负时要分段讨论。（例：曲线 y=x^{1+x}/(1+x)^x：k=e^{−1}，b=(2e)^{−1}，斜渐近线 y=e^{−1}x + (2e)^{−1}。）

第 3 章　微分中值定理与导数的应用▾

这一章的分值最重（本卷 4 套共 22 题，其中证明题几乎全在这里）。它的逻辑主线只有一条：中值定理把「函数值的关系」翻译成「导数值的关系」，剩下的都是把结论形式凑成某个函数的导数。

3.1 罗尔定理与辅助函数构造▾

一句话：要证「存在 ξ 使某等式成立」，就把等式移项写成 F′(ξ) = 0 的样子，那个 F 就是要构造的辅助函数。

为什么：罗尔定理说：F 在 [a, b] 连续、(a, b) 可导、且 F(a) = F(b)，则存在 ξ 使 F′(ξ) = 0。所以用它的唯一门槛是「两端点函数值相等」。证明题的困难全在怎么把要证的式子凑成某个 F 的导数——凑出来了就是找两个相等的 F 值，套定理。

怎么做（构造法，按结论形式对号入座）：

要证 取 F
f′(ξ) = k f(x) − kx
f′(ξ) + λf(ξ) = 0 e^{λx}f(x)
f′(ξ) + g′(ξ)·f(ξ) = 0 e^{g(x)}f(x)
f(ξ)f′(ξ) = 0 型 / 出现 ff″ + (f′)² f(x)f′(x)
f′(ξ) = 2ξ f(x) − x²
结论里出现 f 的积分 ∫₀ˣf(t)dt − 某函数

原理（为什么这招成立）：罗尔定理要求端点的函数值相等，而题设往往不直接给，于是要造一个辅助函数把「结论」搬到「条件」上。微分方程法的逻辑是：若待证式是 F′(ξ)=0 的形式，那么 F 就是待证结论的一个原函数，而原函数可以通过解微分方程（或乘积分因子）确定；把结论看成方程、解出 F(x)=C 的通解，F 就得到了。常数 K 值法则是当结论中端点与中值可分离时，用端点差商把 K 定成一个常数，从而让辅助函数在两端取等值。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 通用技巧｜微分方程法（万能构造法）：① 把待证结论整体看成一个微分方程，求通解并把通解整理成 F(x)=C 的形式，F(x) 就是辅助函数；② 一阶齐次型 f′+p(x)f=0：通解 f=C·e^{−∫p dx}，即 e^{∫p dx}·f=C，故取 F(x)=e^{∫p dx}f(x)——这就是常说的万能构造法；③ 一阶非齐次型 f′+p f=q：取 F(x)=f(x)e^{∫p dx} − ∫q·e^{∫p dx}dx；④ 二阶情形解出的通解可能给出两个原函数，要挑一个能配合题设（在给定点取等值）的。（例：f 在 [0,1] 可导、f(0)=f(1)=0，证存在 ξ 使 f′(ξ)+f²(ξ)=0：解 y′+y²=0 得 e^{−∫y dx}y=C，构造 F(x)=f(x)e^{∫f dx}，则 F(0)=F(1)=0，罗尔即得 F′(ξ)=0。）
  • 通用技巧｜常数 K 值法（可分离型）：① 适用范围：结论由端点 a、b 与中值 ξ 构成，且中值与端点可分离。判别办法：令 b=a 代入待证式，若等式仍成立（成为零式），就可考虑 K 值法；② 第一类：令 K=(f(b)−f(a))/(b−a)，构造 F(x)=[f(x)−f(a)]−(x−a)K，则 F(a)=F(b)=0；③ 第二类：把端点分离成 f(b)−Kb=f(a)−Ka 的形式，构造 F(x)=[f(b)−f(x)]−(b−x)K，则 F(b)−F(a)=0；④ 可分离型也可改走柯西中值定理：从含 a、b 的一侧凑 [F(b)−F(a)]/[G(b)−G(a)]，从含 ξ 的一侧积分还原成 F′(ξ)/G′(ξ)。（例：b>a>0，证 (f(b)−f(a))/(b−a)=ξ²f′(ξ)/(ab)：K 值法与柯西中值定理（取 F(x)=f(x)、G(x)=−1/x）都能做。）

3.2 拉格朗日中值定理与不等式证明▾

一句话：出现 f(b) − f(a)、ln(n+1) − ln n、或「区间长度 × 导数值」时用拉格朗日：f(b) − f(a) = f′(ξ)(b − a)，ξ 在区间内部。

为什么：拉格朗日定理是「增量 = 平均变化率 × 区间长度」。它的用法有两类：

  • 数 ξ 的位置：把 f′(ξ) 解出来（常常 ≈ 某个展开式的比值），再取极限；
  • 证不等式：把待证式子整理成 f(b) − f(a) 与 (b − a) 的比，用 f′ 的单调性给 f′(ξ) 定界（m(b−a) ≤ f(b) − f(a) ≤ M(b−a)）。

原理（为什么这招成立）：三个中值定理的结构差别在于「用到了几个函数的增量」：罗尔只涉及一个函数且两端值相等；拉格朗日涉及一个函数的增量比；柯西涉及两个函数增量之比。所以整理结论时，只含端点与中值、无导数就考虑介值定理；含一个函数导数用拉格朗日；出现两个函数用柯西。用拉格朗日证不等式的关键是把差商换成某点导数后，用该点导数的界估计范围。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 通用技巧｜三种中值定理对号入座：① 结论不含端点优先罗尔；含端点用拉格朗日或柯西；② 整理结论时把一侧写成只含端点、另一侧只含中值：分母是端点相减选拉格朗日；分母不是端点相减（出现两个函数增量比）选柯西；③ 结论中出现两个函数、形式与柯西相似，直接想柯西中值定理；④ 只有介值定理和积分中值定理的中值属于闭区间；拉格朗日是连接 f 与其导数的桥梁。（例：没有思路时，先把 f(b)−f(a)=f′(ξ)(b−a) 写在旁边，再想办法把待证式往这个标准形式上变形。）
  • 通用技巧｜万能构造法证不等式（乘 e 的因子加单调性）：① 条件里出现 f′−f（或 f′+af）时，构造 F(x)=f(x)e^{−x}（或 f(x)e^{ax}）；② 求 F′ 的符号得到 F 的单调性，再由端点的值和单调性推出目标不等式；③ 积分不等式同法：如 ∫_0^1|f′−f|dx≥1/e，令 F=f·e^{−x}，再逆用牛顿-莱布尼茨公式把 1/e 写成 F′ 在 [0,1] 上的积分。（例：f(0)=1、f′(x)0）：令 F=f(x)e^{−x}，F′=e^{−x}(f′−f)<0，故 F(x)<F(0)=1，即 f(x)<e^x。）
  • 通用技巧｜把待证式往定理的标准形式靠拢：① 观察结论中变量是否分离：f(b) 与 f(a) 分离且共用一个法则 f，常把两边同除某量（如 ab）凑出 [f(b)−f(a)]/(b−a) 与 f′(ξ)；② 判型口诀：结论中无导数往介值定理想；有导数且只有一个法则 f 用拉格朗日或罗尔；有两个法则用柯西；③ 出现二阶导数一般用两次中值定理；题目分两问时，第二问务必用第一问的结论。（例：见到结论里同时出现 f 与 g 两个法则，直接定位柯西中值定理，把两个函数分别当作 F 与 G。）

3.3 泰勒公式与积分不等式▾

一句话：结论里出现 f″、二阶导的符号、或「函数值 vs 中点/平均值」时用泰勒公式，在区间中点展开。

为什么：泰勒公式是「用一点的各阶导数还原函数值」，带拉格朗日余项的泰勒是等式（不是近似），所以能用来证不等式。选在中点展开，是因为奇次项在以中点为心的区间上积分正好为 0，能自动消掉——这就是中点不等式那类题的固定套路。

怎么做：① 选展开中心（中点 (a+b)/2 或极值点）；② 写成带拉格朗日余项的形式；③ 对不等式两侧在 [a, b] 上积分；④ 用 ∫(x − m)dx = 0 消去一次项。

原理（为什么这招成立）：泰勒公式在证明不等式与积分估计中的作用是把函数在某点（通常是中点或端点）展开，用余项给出误差的阶。当结论里同时出现函数与二阶导数，或同时出现积分与导数时，说明信息量不止一阶，必须用泰勒（或两次中值定理）才能把两端联系起来。展开点的选择取决于题设里已知函数值或导数值的点——在哪点已知信息多，就在哪点展开。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 通用技巧｜积分不等式的两个判定准则：① 结论中只有积分与被积函数本身，一般用积分中值定理；② 结论中出现积分与被积函数的导数，把变上限积分在某点展成泰勒展开式；③ 积分中值定理的加强版（中值属于开区间）要引用必须先自行证明；④ 泰勒与中值定理是局部近似与区间中值的递进：泰勒是中值定理的高阶推广，拉格朗日是泰勒的一阶特例。（例：∫_0^1|f′−f|dx≥1/e 这类题：先用积分中值定理把左边变成单点值，再构造 e^{−x} 因子走单调性。）
  • 通用技巧｜泰勒展开的展开点与阶数原则：① 常用麦克劳林展开必须背熟，它比反复洛必达更快、更好用；② 求极限时展开原则是上下同阶：分子分母展开到同一阶即可，不要多展；③ 分子分母是差函数时，先分别展开再相乘、挑出所需次数；记熟后要广义化，不要局限在 x→0 的形式；④ 泰勒多项式就是去掉佩亚诺余项剩下的多项式；佩亚诺余项适合局部估计，拉格朗日余项能给出具体误差。（例：把 e^x、sin x、cos x、ln(1+x)、(1+x)^α 的展开式背到条件反射，本章大部分证明题都能少走弯路。）
  • 通用技巧｜辅助多项式法（高阶中值结论）：① 结论要求 n 阶导数的信息，就构造 n 次辅助多项式，使它在题设已知点处与 f 取相同函数值；② 令 F(x)=f(x)−p_n(x)，则 F 在这些点处为零，反复用罗尔可得 F 的 n 阶导在某点为零，即 f 的 n 阶导等于 p_n 的 n 阶导；③ n 次多项式的 n 阶导数是常数，直接算出即为结论里的值。范围不宽但是很好的兜底方法。（例：f 在 [0,4] 二阶可导、f(0)=0、f(1)=1、f(4)=2，证存在 ξ 使 f″(ξ)=−1/3：令 p₂ 过三点得 p₂(x)=−x²/6+7x/6，则 F=f−p₂ 在 0、1、4 处为零，两次罗尔得 F″(ξ)=0，而 p₂″=−1/3。）

3.4 单调性与极值（含变限积分函数）▾

一句话：单调性看 f′ 的符号；极值候选点 = 驻点 + 不可导点（常常被漏掉）；变限积分函数先求导再判。

为什么：极值的第一充分条件是「f′ 在 x₀ 两侧变号」，它对不可导点同样有效——只要函数在那里连续。所以 x|x|、x ln x 这类在 0 处不可导但取极值的函数，只能靠「两侧符号变化」判定，用 f″ 的第二充分条件会失效（f″ 不存在）。

怎么做：① 求 f′，求所有 f′ = 0 的点；② 补上「f 连续但 f′ 不存在」的点（分段点、|x| 型、ln 型）；③ 列表判符号；④ 变限积分函数求导时注意「被积函数里含 x 的项」要用乘积法则，很多题的项刚好相消，化简后再判。

原理（为什么这招成立）：单调性由导数的符号决定，是因为 f(x₂)−f(x₁)=f′(ξ)(x₂−x₁)，差值的正负完全由中点导数的正负决定。极值点必须是「导数变号」的点：导数恒正或恒负的区间内函数严格单调，取不到极值；而导数不存在的点也可能是极值点（尖点处的折返），所以驻点与不可导点都要列入候选。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 通用技巧｜求单调区间与极值的标准步骤：① 先求定义域（单调区间必须是定义域的子集）；② 求 f′，解 f′=0 得全部驻点，并找出 f′ 不存在的点；③ 用驻点与不可导点把定义域分段，逐段判断 f′ 的符号：f′>0 增、f′<0 减，个别点 f′=0 不影响单调性；④ 极值点只能从驻点或不可导点中产生，判极大极小要看两侧 f′ 的符号变化，不能只看 f′=0；⑤ 区间不连续时单调区间要分开写、用逗号连接，不能用并集符号。（例：求单调区间的规范答卷：先写定义域，再列分段表（区间、f′ 符号、f 的增减），最后按段写结论且不写并集。）
  • 通用技巧｜极值最值的分类点比较法：① 候选点三类：驻点、不可导点、端点；② 分别算出这些点的函数值，逐一比较，最大者为最大值、最小者为最小值；③ 区间上只有一个极大（极小）值点时，可结合实际背景直接断定它就是最大（小）值点。（例：闭区间最值题固定三步：列候选点、算函数值、比较大小；漏掉端点是最常见的错。）

3.5 方程根的个数▾

一句话：把方程写成 g(x) = k 或 F(x) = 0，用单调性数出每个单调区间上最多一个根，再用端点（或 ±∞）的符号确认那里确实有根。

为什么：零点定理告诉你「变号 ⇒ 有根」，单调性告诉你「单调 ⇒ 至多一根」。两个结论一夹，根的个数就定死了。含参数的问题（求 k 的范围使方程有几个根）本质是「让水平线 y = k 与曲线交几次」，也就是数极值点的高度把 y 轴分成几段。

怎么做：① 求 f′，列表得出单调区间与极值；② 在每个单调区间上用零点定理（取端点或极限符号）；③ 极值恰好为 0 的「临界情形」要单独说（那是一个重根，不计入「不同根」）。

原理（为什么这招成立）：零点个数问题本质是「单调区间内至多一个根」加上「每个区间内至少一个根」两个方向的计数：单调性给上界（导数不变号就至多一个零点），零点定理给存在性（区间两端异号就至少一个）。所以完整解法是把定义域按驻点与不可导点分段，逐段判两端符号与单调性，最后汇总，并把参数取临界值时根合并的情形单独讨论。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 通用技巧｜零点定理加单调性确定实根个数：① 存在性：用零点定理（区间两端函数值异号，或端点与无穷远极限值异号）判定至少有一个根；② 唯一性：用 f′ 的符号确定单调区间，每个单调区间内方程至多一个根；③ 根的个数等于各单调区间内是否有根之和：区间两端（或极限）异号则该区间恰有一根，同号则该区间无根；④ 要把端点值、极值以及 x 趋于正负无穷的极限趋势都算进来，才不漏临界情形。（例：讨论方程 f(x)=0 的根：列表写出 f 在每段上的单调性与两端符号，逐段判「有且仅有」，最后汇总个数。）
  • 通用技巧｜罗尔定理数零点（求零点个数上界）：① 核心引理：函数两个零点之间至少有一个导数为零的点，故 n 个零点推出导函数至少 n−1 个零点、二阶导至少 n−2 个零点；② 反证法：假设有 n 个零点，反复求导（必要时乘 e^{−ax} 之类的因子保持零点个数不变）把项数逐次减少；③ 求导到某一步得到显然无解的方程，矛盾即得零点个数的上界。（例：形如 Σc_k e^{a_k x}（各 a_k 互异）的函数至多 n−1 个不同零点：乘 e^{−aₙx} 后反复求导，最后得一个指数等于零的方程无解，与假设矛盾。）
  • 通用技巧｜用极值最值讨论根的个数：① 先求单调区间和极值（极大值、极小值）；② 把极值点与 0 比较：极大值小于 0 或极小值大于 0 则无根；极值异号则在相应单调区间内各有一根；③ 再结合 x 趋于正负无穷时 f 的趋势判断多根与临界情形。（例：含参方程根的个数题：先算极值，再让参数在「极值等于 0」的临界值两侧分类讨论，答案写成区间。）

3.6 凹凸性与拐点▾

一句话：凹凸看 f″ 的符号，拐点是 f″ 变号的点；f″ = 0 但不变号的地方不是拐点。

为什么：f″ > 0 表示 f′ 递增（切线斜率越来越大），曲线向上弯——这是「凹」（教材上叫凹/凸的约定各不同，判断只认符号变化）。拐点的定义要求凹凸性改变，所以光有 f″ = 0 不够，必须检查两侧符号。

怎么做：① 求 f″，解 f″ = 0；② 检查每个零点两侧 f″ 是否变号；③ 拐点坐标是 (x₀, f(x₀))，题目再问切线就顺手求 f′(x₀)。

原理（为什么这招成立）：凹凸性由二阶导数符号刻画：二阶导数大于 0 时一阶导数递增，切线斜率越来越大，曲线向上弯（凹）。拐点是凹凸性改变的点，因此必须要求二阶导数在该点两侧异号；二阶导数为 0 只是「可能改变」的必要条件，像 x⁴ 在 0 处两侧都凹，虽然二阶导为 0 却不是拐点。

3.7 渐近线▾

一句话：三种渐近线各查一处——铅直：函数发散的点；水平：x → ±∞ 时 y 的极限；斜：同一方向上「没有水平渐近线」时才算 a = lim y/x、b = lim (y − ax)。

为什么：渐近线的定义是「曲线到直线的距离趋于 0」，所以水平渐近线是斜渐近线的特例（a = 0）。这就是为什么同一侧有水平渐近线就不再有斜渐近线——不是规则命令，而是「距离趋于 0 的直线最多一条」。

怎么做：① 找使 y → ∞ 的有限点 → 铅直；② 算 x → ±∞ 的极限 → 水平；③ 若某侧极限不存在（或为 ∞），再算 a、b 得斜渐近线。

原理（为什么这招成立）：渐近线刻画的是曲线在「无穷远或间断点附近」与某条直线的接近程度：垂直渐近线对应函数值发散（间断点），水平渐近线对应函数值趋于常数，斜渐近线对应函数值与某条直线的差趋于 0——后者展开成 f(x)=kx+b+o(1) 就得到 k 与 b。同侧不可能既有水平渐近线又有斜渐近线，因为函数值趋于常数时 f(x)−kx 必发散。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 通用技巧｜三类渐近线的定义式求法：① 垂直渐近线：若 f 在 x₀ 一侧或两侧趋于无穷，则 x=x₀ 是垂直渐近线（x₀ 为无穷间断点）；可以有多条；② 水平渐近线：若 x 趋于正无穷或负无穷时 f 趋于常数 A，则 y=A 是水平渐近线，至多两条（两侧各一条）；③ 斜渐近线：先算 k 为 f(x)/x 在无穷远处的极限，再算 b 为 f(x)−kx 的极限，则 y=kx+b 是斜渐近线，也至多两条；④ 求斜渐近线要算两次极限，最容易漏算截距 b；而且 k 存在还不够，必须验证 f(x)−kx 的极限存在（反例：f(x)=x+ln x，k=1 但没有斜渐近线）。（例：同一侧若有水平渐近线，该侧就不必再求斜渐近线——这条把「求渐近线条数」的题变成简单计数。）
  • 通用技巧｜计算顺序固定：垂直、水平、斜：① 关键结论：水平渐近线与斜渐近线加起来最多两条，同侧不可能既水平又斜；② 计算顺序固定为垂直渐近线、水平渐近线、斜渐近线；③ 计数类题目按这个顺序清点，避免重复计数。（例：清点条数：先找所有无穷间断点（垂直），再看两侧趋于常数的情况（水平），剩下的侧才去求斜渐近线。）

3.8 闭区间上的最值▾

一句话：闭区间最值 = 比较「所有驻点 + 不可导点 + 两个端点」的函数值，取最大最小。

为什么：连续函数在闭区间上必取到最值，而最值点只可能是「内部的可导极值点（驻点）」「内部的不可导点」或「端点」。这是把「无限多」压成「有限多个候选」的定理保证。

原理（为什么这招成立）：闭区间上连续函数必取到最大最小值（最值定理），所以最值只可能在驻点、不可导点或端点取得，这三类点因此构成全部候选。开区间上最值可能取不到（函数在端点附近趋于极值），所以必须改用单调性与极限来讨论。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 通用技巧｜闭区间上最值的三类点比较法：① 第一步：在 [a,b] 上找出三类候选点——驻点、不可导点、端点；② 第二步：分别计算这些点处的函数值；③ 第三步：比较大小，最大者即最大值、最小者即最小值；④ 区间必须是闭区间才保证最大值最小值一定取到；开区间要改用极限或单调性讨论。（例：闭区间最值题一律三步走，绝不要只比较驻点；端点值必须算。）
  • 通用技巧｜唯一极值法与实际应用最值：① 讨论区间上只有一个极大（极小）值点时，该点可结合实际背景直接判为最大（小）值点；② 实际应用题先做三件事：确定目标函数、写出约束条件、判定所讨论的区间；③ 含参数的闭区间最值要讨论驻点或端点是否落在区间内，分类处理。（例：应用题里出现「唯一驻点」时，可用单调性或实际意义直接断定它是最大（小）值点，不必再算端点。）

3.9 参数取值范围：单调性 + 端点极限▾

一句话：把参数从方程里解出来，让它等于一个不含参数的函数值域。

为什么：方程 F(x, k) = 0 在区间内有解 ⟺ k = g(x) 在区间内取到（g 是不含 k 的表达式）。于是问题从「解方程」变成「求 g 的值域」——值域 = 单调区间的两端值（或极限）之间的一切。

怎么做：① 把 k 单独解出来；② 对 g 求导定单调性（通常要用一个次级不等式，如 ln(1 + x) < x 来证明 g′ < 0）；③ 算区间两端的 g 值/极限，值域即所求；④ 端点能否取到要单独说明。

原理（为什么这招成立）：恒成立问题转化为最值问题，是因为「对一切 x 都成立」等价于「不等式在最坏的那个点上也成立」，而最坏点就是最大（最小）值点。分离参数之所以优先，是因为分离后不等式右边是不含参数的函数，参数范围直接等于该函数的最值，不需要按参数分类讨论。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 通用技巧｜恒成立等价于最值（把参数范围问题转化为值域问题）：① 对所有 x 有 f(x)a 恒成立等价于 f(x) 的最小值大于 a；② f(x)<g(x) 恒成立：令 F=f−g，只需 F 的最大值小于 0；③ 存在性：存在 x₀ 使 f(x₀)a 等价于 f 的最大值大于 a；④ 双变量：对所有 x₁ 存在 x₂ 使 f(x₁)<g(x₂)，等价于 f 的最大值小于 g 的最大值；对任意 x₁、x₂ 都成立则等价于 f 的最大值小于 g 的最小值。（例：所有这类题都归到一句话：参数范围就是某函数的值域，把范围求出来即得答案。）
  • 通用技巧｜分离参数法（首选）：① 先把不等式化为参数大于 h(x) 或参数小于 h(x) 的形式，使参数与 x 分离；② 参数大于 h(x) 恒成立等价于参数大于 h(x) 的最大值；参数小于 h(x) 恒成立等价于参数小于 h(x) 的最小值；③ 分离后所得函数不含参，避免了对参数分类讨论，是首选做法；④ 若分离后 h(x) 的最值难求，再退回直接构造函数求最值或数形结合。（例：凡是含参恒成立题，先试分离参数；能分离就别分类讨论，这是等价变形不是技巧性操作。）
  • 张宇｜把含参问题定位为「最值或值域」题型：① 含参问题先定位到求某函数的值域，再回到单调性、极值、渐近线去卡出范围的上下界；② 顺序上先做单调性与极值，再看 x 趋于端点或无穷远处函数值的极限，两端合起来即为值域，参数范围随之确定；③ 这套定位与切线法线、单调性极值凹凸拐点、渐近线并列，是微分学应用的核心题型。（例：看到「恒成立」「有两个实根」「至少有一个交点」这类问法，统一翻译成值域问题，再用单调性和端点极限算值域。）

第 4 章　不定积分▾

本章题量不大但最容易丢分在「算不完」。两句总纲：先看能不能凑微分（换元），再看是不是两类函数的乘积（分部），最后看是不是有理函数（部分分式）。做题前先给被积函数分类，比盲目试公式快得多。

4.1 分部积分▾

一句话：被积函数是「多项式 × 超越函数」「反三角/对数 × 其它」时用 ∫u dv = uv − ∫v du，选 u 的顺序按 「反对幂指三」（反三角、对数、幂函数、指数、三角，排在前面的当 u）。

为什么：分部积分是把「难算的积分」换成「另一个积分」。选谁当 u 的原则是求导后变简单：反三角、对数求导后变成代数式（变简单），而多项式求导后降次。选对了，第二项就比第一项好算。

怎么做：① 按口诀定 u、dv；② 若一次分部后还是乘积型，再分部一次；③ 出现「循环」（如 ∫e^x sin x）就移项解出原积分；④ 结果别忘 + C。

原理（为什么这招成立）：分部积分来自乘积求导公式 (uv)′=u′v+uv′ 的移项积分，作用是把「难积的乘积」换成「容易积的另一半」：∫u dv=uv−∫v du，所以选 u 的原则是求导后变简单（多项式、对数、反三角），选 dv 的原则是容易积分（指数、三角）。循环型出现的原因是 e^{ax} 与 sin bx 各自求导积分都不改变形态，两次分部后回到原积分，于是得到关于自身的方程。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 张宇｜分部积分的推广公式：表格法：① 把乘积型积分中的 u 放在表格第一行一直往下求导，dv 对应的函数放在第二行一直往下求原函数；② 上下对应项相乘，符号按正负交替加和，最后一项写成积分形式，符号由交替规则决定；③ 适用条件：其中一部分（通常是多项式）反复求导后变成 0，或求导积分若干次后出现与自身成倍数的循环项；④ 表格法与基本积分公式、凑微分、第二类换元法并列为不定积分计算的第四类方法。（例：∫x²e^x dx：第一行写 x²、2x、2、0，第二行写 e^x 的连续几次原函数，交叉相乘即得，不必反复分部。）
  • 通用技巧｜表格法的操作步骤与符号规则：① 第一行写需要求导的因子及其各阶导数，第二行写需要积分的因子及其各次原函数；② 从左上角开始交替标注正负，每行对应项相乘后按符号相加，直到某一列为 0 或出现可回代的循环项；③ u 通常选容易求导的因子，dv 选容易积分的因子；两个因子都不好积分时表格法不会简化，反而更繁琐。（例：表格法本质是分部积分公式的多次展开，用表格把反复分部的符号交替固定下来，减少写错符号的概率。）
  • 通用技巧｜u 的选择顺序口诀：反对幂指三：① 顺序为反三角函数、对数函数、幂函数、指数函数、三角函数（指数与三角互换则为反对幂三指）；② 排在前面的取作 u，排在后面的与 dx 一起凑成 dv；③ 两种说法只在指数与三角谁先谁后有差别；当二者同时出现（循环型）时顺序可以互换，因为要做两次分部积分；④ 口诀只是经验总结不是定理，个别题需要灵活换序。（例：∫x³e^{x²}dx 幂函数取 u；∫(ln x−1)/x² dx 对数函数取 u。）
  • 通用技巧｜循环积分型：两次分部后移项解方程：① 被积函数为 e^{ax}·sin bx、e^{ax}·cos bx、sin ax·cos bx 这类求导或积分两次又变回自身的组合时，连用两次分部积分；② 第二次分部后等式右边出现原积分的倍数，把原积分移到一边解方程得到结果；③ 只要数次分部后出现的新积分与原积分成倍数关系（如含 sin(a ln bx) 的情形），都用移项办法；④ 含正整数次幂时得到的是递推式而不是方程。（例：∫e^x cos x dx = e^x(sin x + cos x)/2 + C——两次分部后右边出现同一个积分，移项即得。）

4.2 第二类换元：三角代换与根式代换▾

一句话：见到 √(a² − x²)、√(a² + x²)、√(x² − a²) 就用三角代换把根号变成三角函数（去根号）；代换后必须回代到原变量。

为什么：根号是计算的最大障碍，而三角恒等式 1 − sin²t = cos²t 正是为消根号准备的。反过来，若被积函数里出现 e^t、arcsin 这类「反过来的」结构，也可以令 x = tan t，把代数式变成指数/三角式（本卷的 2003 数二题就是这一型）。

怎么做：① 按根号形式选代换（√(a²−x²): x = a sin t；√(a²+x²): x = a tan t；√(x²−a²): x = a sec t）；② 换元后化简成三角式并积分；③ 回代：画一个直角三角形或用恒等式把 sin t、tan t 换成 x 的表达式。

原理（为什么这招成立）：三角代换的依据是勾股恒等式能把根号内的平方和差变成完全平方，从而整体开出根号；这等价于用圆或双曲线的参数方程表示曲线。根式代换的依据是反解：把整个根式设为 t 后，x 是 t 的有理函数，dx 也是 t 的有理式，无理积分因此变成有理函数积分，而后者有固定的部分分式流程。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 通用技巧｜三角代换三型：按根号里的形式对号入座：① 根号内是 a²−x²，令 x=a sin t，用 1−sin²t=cos²t 去根号；② 根号内是 a²+x²，令 x=a tan t，用 1+tan²t=sec²t 去根号；③ 根号内是 x²−a²，令 x=a sec t，用 sec²t−1=tan²t 去根号；④ 根号内不是简单形式时先配方或提系数；⑤ 必须限定 t 的范围（sin 取 [−π/2,π/2]、tan 取 (−π/2,π/2)、sec 取 [0,π/2) 与 [π,3π/2)），才能保证开根号时去掉绝对值。（例：∫√(1−x²)dx 取 x=sin t，结果为 arcsin x /2 + x√(1−x²)/2 + C。）
  • 通用技巧｜回代技巧：画直角三角形把 t 换回 x：① 结果里含有 t 的三角函数时，画直角三角形：由换元关系定出两条边，第三边用勾股定理求出，再直接读出需要的三角函数值；② 结果里只出现 t 本身时，用反三角函数回代，不要用三角形；③ 最后加上任意常数，并把所有 t 都换回 x，不能保留参数 t。（例：∫√(1−x²)dx 中需要 sin 2t，用三角形得 sin 2t=2sin t·cos t=2x√(1−x²)。）
  • 通用技巧｜三角代换为什么可行：三个勾股恒等式：① sin²t+cos²t=1 对应处理 1−x²，用 x=sin t；sec²t=1+tan²t 对应处理 1+x²，用 x=tan t；csc²t=1+cot²t 对应处理与 x²−1 有关的根式；② 本质是用圆或双曲线的参数方程替换根式，把无理式化成 t 的三角有理式；③ 三类根式与三类换元一一对应，看到根号内是什么就能直接对号入座；④ 代换后 dx 也要一并换掉，漏掉 dx 是最常见错误。（例：半圆面积 ∫√(1−x²)dx 在 [−1,1] 上经 x=sin t 化为 ∫cos²t dt，得 π/2。）

4.3 有理函数的部分分式分解▾

一句话：真分式先因式分解分母，再按「每个因式对应一项」拆成简单分式，逐项积分。

为什么：有理函数没有「万能换元」，但有一张完整的对照表：分解后的每一项都能直接积出来（1/x → ln|x|、1/x² → −1/x、一次不可约二次式 → ln + arctan）。所以问题被彻底转化成代数运算——这就是部分分式分解的价值。

怎么做：① 假分式先做除法；② 分解因式；③ 按规则设部分分式（单因式 (x − a) 对应 A/(x − a)；重因式 (x − a)² 要 A/(x − a) + B/(x − a)²；不可约二次式 (x² + px + q) 对应 (Ax + B)/(x² + px + q)）；④ 用「代特殊值 + 比较系数」求 A, B…（最快的是把分母乘过去再代根的值）。

原理（为什么这招成立）：有理函数的积分之所以能算法化，是因为实系数多项式总能分解成一次因式与不可约二次因式之积，而这两类因式对应的简单分式都有初等原函数（对数、反正切）。所以分解时重因式必须写满次数、二次因式分子必须是一次式，才能保证每一项都能积出来。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 通用技巧｜先分真假：假分式（分子次数不低于分母）先做多项式除法：① 真分式：分子次数低于分母次数；假分式：分子次数不低于分母次数；② 假分式用多项式长除法化为多项式加真分式，多项式部分直接逐项积分，只对真分式做部分分式分解；③ 分解的目标是把分母高于二次的分式拆成一批最简单真分式之和，因为基本积分表里只有分母是一次式或二次式这两类公式。（例：∫(x³+1)/(x²+1)dx 先用除法化为 ∫[x + (−x+1)/(x²+1)]dx，再分别积分。）
  • 通用技巧｜分母因式对应的部分分式形式：重因式写满 m 项：① 把分母完全分解成一次因式与实数域上不可约二次因式（判别式小于 0）的乘积；② 对 m 重一次因式必须写 C₁/(ax+b) + C₂/(ax+b)² + … + Cₘ/(ax+b)ᵐ 共 m 项，不能只写一项；③ 对不可约二次因式，分子要写成一次式；若是它的 n 次幂，则每一幂次都配一个一次分子；④ 待定系数个数与部分分式的最高次数相同，可作为检查是否漏项的依据。（例：2/(x−2)³ 应写成 C₁/(x−2) + C₂/(x−2)² + C₃/(x−2)³ 三项；含 (x−1)²(x²+x+1) 的分母同时用重因式与不可约二次因式两种形式。）
  • 通用技巧｜定系数：代特殊值加比较系数（含覆盖法）：① 两边同乘公分母得到恒等式，再比较同次项系数，或代入使某些项为 0 的特殊 x 值；② 单重一次因式的系数可用覆盖法（把该因式遮住、代 x 取其根）快速求出；③ 重因式与二次因式不能用覆盖法一次求完，需要代入多个 x 值或比较系数解方程组；④ 分解完成后逐项套基本积分表积分，不要漏掉任意常数。（例：∫dx/(x²−3x+2) = ∫[1/(x−2) − 1/(x−1)]dx = ln|(x−2)/(x−1)| + C。）

4.4 分段函数的原函数：连续性定常数▾

一句话：分段函数的原函数必须连续（可导必连续），所以各段的任意常数之间只差一个由连续性方程定出的数。

为什么：原函数是可导函数，而可导 ⇒ 连续。所以「分段积分出来的两段」如果不连续，就根本不是同一个函数的原函数。连续性方程恰好把 n 个常数压成 1 个自由常数（真正的任意常数 C 只有一个）。这正是选择题里那四个选项的区别所在：只有常数配对的才连续。

原理（为什么这招成立）：分段函数的原函数之所以要用连续性定常数，是因为「原函数」要求在整个区间上可导，而可导必连续，所以各段原函数在分段点必须接得上。每段各有一个任意常数，连续性给出各常数之间的等式，把自由度从 n 个降到 1 个，这才是完整的原函数族。用变上限积分法可以一次性得到连续的那个原函数，本质上是把「连续」这个条件直接构造进表达式里。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 通用技巧｜分段函数求不定积分：分段求原函数，再用连续性定常数：① 先把函数写成真正的分段形式（含最大值、最小值、绝对值、取整的先化成分段）；② 逐段求原函数，各段各带一个任意常数；③ 因为原函数一定连续（可导必连续），在分段点令左右极限相等，得到各常数之间的关系式；④ 求出关系后只保留一个独立常数，把其他常数用它的表达式替换，写成连续的分段表达式；只写三个独立常数就停手是最常见的失分点。（例：f(x)=max{1,x²}：三段原函数在 x=−1 与 x=1 处连续，定出常数关系，最终写成只含一个任意常数的连续分段表达式。）
  • 通用技巧｜变上限积分法：直接得到连续原函数，绕开定常数：① 若 f 连续，则变上限积分 ∫a^x f(t)dt 就是 f 的一个连续原函数，不必再讨论各段常数之间的关系；② 下限 a 取在分段点上（如 0），再把积分按 x 所在的段拆成相邻区间上定积分之和；③ 结果再加一个任意常数就是全部不定积分；此处分段是为了符合 f 的定义，不是把积分区间乱分段。（例：∫max{1,x²}dx 取 G(x)=∫_0^x max{1,t²}dt：当 x<−1 时拆成 ∫_0^{−1}1dt + ∫^x t²dt = x³/3 − 2/3。）
  • 张宇｜先判断原函数是否存在，再谈定常数：① 若 f 连续，则区间内必有原函数（变上限积分就是）；② 若 f 含第一类间断点或无穷间断点，则在包含该点的区间内原函数必不存在，不能写原函数符号；③ 若含振荡间断点，可能有原函数，关键是看能否写出原函数的形式。（例：分段点若是跳跃间断点，则该区间没有原函数，题目问「下列哪个是 f 的原函数」可直接排除选项。）

4.5 原函数的性质（奇偶、周期、单调）▾

一句话：奇函数的原函数都是偶函数（且都满足 F(0) = 0 的那个是唯一的偶原函数）；偶函数的原函数中只有一个奇函数；周期函数的原函数不一定周期。

为什么：由 F(x) = ∫₀ˣ f(t)dt + C 直接看：f 为奇函数时 ∫₀^{−x} f = −∫₀ˣf(−u)du = ∫₀ˣ f(u)du（用了 f(−u) = −f(u)），恰是偶函数的形式；f 为偶函数时 ∫₀^{−x} f = −∫₀ˣf(u)du，只有当 C = 0 时才得到奇函数。周期性最容易错：原函数只有在「f 在一个周期上的积分为 0」时才是周期函数。

原理（为什么这招成立）：原函数的奇偶性由积分区间关于原点对称时的抵消效应决定：奇函数在对称区间上积分为 0，所以它的原函数在关于原点对称的点处取值相同（偶函数）；偶函数在对称区间上的积分不为 0，只有从 0 开始积（即加常数使过原点）才可能成为奇函数。周期性则要求一个周期上的积分为 0，否则原函数每过一个周期就整体平移，不再是周期函数。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 通用技巧｜原函数的奇偶性：奇函数的原函数都是偶函数：① 连续的奇函数的一切原函数都是偶函数；② 连续的偶函数的原函数中仅有一个是奇函数，就是过原点那个，即 ∫_0^x f(t)dt；其余原函数都在它基础上加常数，因而不再奇；③ 对偶函数求原函数时不能直接断定结果是奇函数，必须加条件原函数在原点为 0；④ 配套结论：可导的偶函数其导函数是奇函数，可导的奇函数其导函数是偶函数。（例：反例：f(x)=cos x 是偶函数，但它的原函数 sin x+1 不是奇函数；只有 sin x（即从 0 积到 x 那个）才是奇函数。）
  • 通用技巧｜原函数的周期性：必须先用「一个周期上积分为 0」作条件：① 可导的以 T 为周期的函数，其导函数也以 T 为周期；② 连续函数 f 以 T 为周期时，只有当 f 在一个周期上的积分为 0，f 的一切原函数才都以 T 为周期；积分不为 0 时，原函数中没有周期函数；③ 所以「周期函数的原函数是周期函数」这句话是错的，条件是附加的；④ 常用反例：f(x)=1 是周期函数，但它一个周期上的积分不为 0，原函数 x+C 不是周期函数。（例：f(x)=sin x 在一个周期上积分为 0，故原函数 −cos x+C 是周期函数；f(x)=1 与 F(x)=x 则是反例。）
  • 通用技巧｜原函数族：任意两个原函数只相差常数：① 若 f 在区间 I 上有原函数 F，则 f 的全体原函数为 F(x)+C，任意两个原函数之差为常数；② 用不同方法算出两个形式不同的结果时，二者之差必为常数，可用来检验答案或判断是否属于同一原函数族；③ 判断原函数单调性要回到其导数即 f 的符号上，不能沿用 f 的单调性；④ 求出的原函数一定连续、处处可导，否则它不可能是任何函数的原函数。（例：∫sin x cos x dx 写成 sin²x/2 + C₁ 或 −cos²x/2 + C₂ 都对，两者相差 1/2，属于同一原函数族。）

4.6 基本积分表、凑微分与换元▾

一句话：先把被积式凑成某个基本积分表里的形式（凑微分），再代公式。

为什么：不定积分 90% 的工作是「识别」，而不是「技巧」。基本积分表只有二十来条，但题干可以千变万化——所有的变化都靠换元 u = u(x) 把它拉回表内。所以看到陌生的式子，第一反应是问「它像表里的哪一条」。

原理（为什么这招成立）：凑微分的依据是微分形式不变性：∫f(g(x))g′(x)dx=∫f(u)du，只要被积表达式里能认出「某个函数的导数乘以 dx」这个整体，就能整体换元。存在 g′(x)dx=dg(x) 是唯一的判别标准，所以「凑不成基本公式」意味着没认出导数因子，应换另一部分去凑或改用其他方法。

名师方法（公开讲义与题解的通行讲法，出处见下）

  • 通用技巧｜凑微分（第一类换元）的常见结构：① 核心动作：被积表达式里若出现 g′(x)dx，就把它凑成 dg(x)，令 u=g(x)，化为 ∫f(u)du 再套基本积分表；② 常见结构一：f(ax+b)dx 与 f(xⁿ)xⁿ⁻¹dx 型；③ 常见结构二：f(sin x)cos x dx、f(cos x)sin x dx、f(tan x)sec²x dx 型；④ 常见结构三：f(e^x)e^x dx、f(ln x)(1/x)dx、f(1/x)(1/x²)dx 型；⑤ 凑不成基本积分公式里的形式，说明方向不对，应换另一部分去凑。（例：∫(1/x²)sin(2/x)dx = −∫sin(2/x)d(1/x) = (1/2)cos(2/x) + C。）
  • 通用技巧｜基本积分表必须背到条件反射（含绝对值与定义域）：① 必背：幂函数、指数函数、正余弦、正割正切与反三角的十余个基本公式，注意对数要加绝对值；② 常考补充：分母为二次式的反正切型、根式为平方和的取对数型、正割与余割的积分公式；③ 凑微分、第二类换元、分部积分的目的都是把新积分化归到这张表上的某一项。（例：考试口径是「基本积分公式直接套」：拿到一个积分先想它像表里的哪一条，再想怎么凑成那一条。）
  • 武忠祥｜不定积分方法选用顺序：基本公式、凑微分、换元、分部、有理函数：① 先看能否直接拆项套基本积分表；② 不行就找 g′(x) 凑微分（第一类换元）；含根式且凑不出来用第二类换元（根式代换或三角代换）；③ 被积函数是两类函数相乘时用分部积分，u 按反对幂指三的优先顺序选取；若被积函数中只有反三角函数或只有对数函数，直接分部积分；④ 有理函数用部分分式分解；三角有理式优先用倍角公式与凑微分，必要时再用万能代换。（例：∫x²e^{−2x}dx 走分部、∫ln x dx 直接分部（u 取对数）、∫dx/(x²−3x+2) 走部分分式——三条路对应三类被积函数。）

极限与连续

  1. 加减位置不能等价替换；相消就展开到第一个不抵消的阶。
  2. 变限积分「求导降一阶」；上限带函数要乘它的导数。
  3. 1^∞ 一律取对数：lim g(f − 1) 就是指数上的极限。
  4. 间断点先约分再逐点判；e^{1/x} 型要分左右两侧。
  5. 比较阶时：阶小 = 趋于 0 慢 = 低阶，排序题别再数反。
  6. x → ∞ 也是 1^∞ 现场；极限点不是 0 就先换元平移到 0。

导数与微分

  1. 抽象函数、分段点：一律用定义凑差商（减掉 f(x₀)）。
  2. 绝对值型看「旁边乘了几次 x」；不可导点也可能是极值点。
  3. 参数方程二阶导 = 对 t 求导后再除以 dx/dt。
  4. 隐函数先定值再求导；二阶导直接代一阶的结果。
  5. 乘法项里的变限积分求导要带乘积法则。

中值定理与应用

  1. 罗尔定理先算两端函数值（相等才能用）。
  2. 证不等式：两半边常常要换辅助函数；用 f′ 的单调性给界。
  3. 极值候选 = 驻点 + 不可导点；闭区间最值别漏端点。
  4. 根的个数：单调性管「至多」，端点符号管「有」；临界情形（极值 = 0）单独说。
  5. 渐近线：同一侧有水平就没有斜；分母为 0 但分子也为 0 的点不是铅直渐近线。
  6. 求参数范围：把 k 解出来 → 求值域 → 端点开闭单独判。

不定积分

  1. 先分类（凑微分 / 分部 / 换元 / 部分分式），再动笔。
  2. 分部：「反对幂指三」，u 选求导后变简单的。
  3. 三角代换后必须回代；代换时别忘 dx 的换算因子。
  4. 部分分式：重因式写两项，不可约二次式分子写 Ax + B。
  5. 分段函数的原函数要连续（常数互相绑住）；tan 型答案求导回验一遍。
  6. 不定积分结果别忘 + C。

通用

  1. 每个答案回头做一次量纲/特值检验（代一个具体数、看符号、看单调方向）。
  2. 计算题写清「解」「由…得」的步骤；证明题写清「由…定理，存在 ξ ∈ (a, b)」——得分点就在这些字上。
